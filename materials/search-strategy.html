Search strategy

This page records every search, as PRISMA-S requires (Rethlefsen et al. 2021). Each query gets one row in the table, and each database gets one entry under search strings. The table counts are the records each database returned before deduplication. 01-deduplication writes the identification counts for the flow diagram from the exports in data/raw/search_exports/ once the exports are in.

Queries

Four queries run in each database for 2015 to 2025. All four build on Chawinga and Zinn (2019). Q1 takes their core term, “research data sharing”, and serves as the base RDS query. Q2 to Q4 extend that term with the vocabulary the field uses around it. Each pairs one key term with “research data” or “data sharing” using AND, so a record must name both the concept and the data practice in its title or abstract. The date range brackets the 2019 review and picks up where it left off. The queries use no health terms. All terms are searched in titles and abstracts.

Seed

The base RDS query (Q1) alone serves as the seed for the screening ranking. It returned 308 records against 4,192 for the four queries combined (7.3%), modestly above the conventional 5%. A seed derived from a fixed keyword is reproducible, and its size stays near where a seed sample should land.

Candidate terms from earlier drafts of the query were checked against the seed. Table 1 shows how often each term appears in the records the base RDS query returned, which guided the four queries above.

Search strings

The generic queries are the database-neutral core of the strings below. Each database adds its own field tags, date limits, and document type filters. All terms are searched in titles and abstracts.

Generic queries

-- Q1: research data sharing (base RDS query)
"research data sharing" OR "research data-sharing"

-- Q2: open data
"open data"
AND ("research data" OR "data sharing")

-- Q3: data governance
"data governance"
AND ("research data" OR "data sharing")

-- Q4: open science
"open science"
AND ("research data" OR "data sharing")

Scopus (1,723 records)

TITLE-ABS ( "research data sharing" OR "research data-sharing" )
AND PUBYEAR > 2014 AND PUBYEAR < 2026

Other sources

Describe each supplementary method and how records were identified: citation searching of the included sources, registries, websites, and contacts. Name export files for these sources with the prefix other-.

Known-item test

The final strings are tested against these sources. The first two groups are in scope, so the query should retrieve them. The last two groups are comparators or adjacent work, and retrieving them is not required.

Export file names

Name each export <database>_<YYYY-MM-DD>[_<query>].<ext>, for example scopus_2026-11-02_q1.ris. The query label is q1, q2, q3, or q4. The date is the search date. Supported formats are RIS and CSV. See the README in data/raw/search_exports/.
