Search strategy

This page records every search, as PRISMA-S requires (Rethlefsen et al. 2021). Each database search gets one row in the table and one entry under search strings. The record counts below are written by 01-deduplication from the exports in data/raw/search_exports/.

Queries

One query runs in each database for 2015 to 2025. It joins two blocks with AND. The first block holds “research data sharing” and related data concepts. The second holds factor terms. The query uses no health terms. The term “research data sharing” alone seeds the screening ranking.

Search strings

The generic query is the database-neutral core of the three strings below. Each database adds its own field tags, date limits, and document type filters. The seed term strings are to be added.

Generic query

(
  "research data sharing" OR "research data-sharing"
  OR "open data" OR "data reuse" OR "data re-use"
  OR "data curation" OR "digital curation"
  OR "data management plan*"
)
AND
(
  barrier* OR challenge* OR obstacle*
  OR facilitator* OR enabler* OR motivat* OR incentive*
  OR attitude* OR perception* OR willingness OR reluctan*
  OR mandate* OR policy OR policies
  OR ethic* OR privacy OR consent OR licens*
  OR infrastructure OR repositor* OR interoperab* OR stewardship
)

Other sources

Describe each supplementary method and how records were identified: citation searching of the included sources, registries, websites, and contacts. Name export files for these sources with the prefix other-.

Known-item test

The final strings are tested against these sources. The first two groups are in scope, so the query should retrieve them. The last two groups are comparators or adjacent work, and retrieving them is not required.

Export file names

Name each export <database>_<YYYY-MM-DD>[_<query>].<ext>, for example scopus_2026-11-02_full.ris. The date is the search date. Supported formats are RIS and CSV. See the README in data/raw/search_exports/.
