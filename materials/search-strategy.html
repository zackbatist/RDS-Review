Search strategy

This page records every search, as PRISMA-S requires (Rethlefsen et al. 2021). Each database search gets one row in the table and one entry under search strings. The record counts below are written by 01-deduplication from the exports in data/raw/search_exports/.

Search blocks

Two blocks run in each database.

Block Concepts combined Limit
A Research data sharing and reuse; factors, barriers, facilitators, and governance; health research None on source type
B Research data sharing and reuse; factors, barriers, facilitators, and governance Review or synthesis filter; no health terms

The query terms of Panhuis et al. (2014) are the starting point for the factor terms. Their public health terms are replaced by research data terms.

Other sources

Describe each supplementary method and how records were identified: citation searching of the included sources and of Panhuis et al. (2014), registries, websites, and contacts. Name export files for these sources with the prefix other-.

Known-item test

Before the full searches run, the final strings are tested against these sources. The first two groups are in scope, so both blocks together should retrieve them. The last two groups are comparators or adjacent work, and retrieving them is not required.

Export file names

Name each export <database>_<YYYY-MM-DD>[_<block>].<ext>, for example scopus_2026-11-02_A.ris. The date is the search date. Supported formats are RIS and CSV. See the README in data/raw/search_exports/.
